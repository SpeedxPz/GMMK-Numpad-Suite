OBS Studio

What the keys, knob and slider do in OBS is set per profile and layer in the Keys tab.

Setup guide

  1. Open OBS Studio (version 28 or newer has the WebSocket server built in).
  2. Go to Tools → WebSocket Server Settings.
  3. Tick Enable WebSocket server. Leave the port at 4455.
  4. Leave Enable Authentication on. The suite reads the password from OBS's own settings on this PC, so you never type it.
  5. Click OK. The OBS chip at the top turns green within a few seconds.
  6. In the Keys tab, set keys to App action → OBS Studio: record, stream, pause, scenes, mute, TAKE, replay buffer. Set the knob or slider to an OBS control.

Optional

  • Replay buffer keys: enable it in OBS → Settings → Output → Replay Buffer.
  • Studio Mode: scene keys and the knob go to Preview; a TAKE key sends it live. The slider can be the T-bar.

Not connecting? Check that OBS is running and that the port in OBS is 4455.

Discord

The secret and the authorization stay on this PC and are not part of backups.

Setup guide

Discord only lets apps that you own control your mic, so you make a small app of your own once (about 2 minutes).

  1. Open the Discord Developer Portal and sign in with your Discord account.
  2. Click New Application and name it, e.g. “GMMK Numpad”.
  3. Open OAuth2 in the left menu. Copy the Client ID into the box on the left.
  4. Click Reset Secret, then copy the Client Secret into the box on the left.
  5. Under Redirects, add http://localhost and click Save Changes.
  6. Open App Testers in the left menu and add your own Discord account (even as the app's owner), then accept the invite. Without it Discord answers invalid_scope.
  7. Here, turn Enabled on and click Save & connect. Discord must be running on this PC (the desktop app, not the browser).
  8. Discord shows an Authorize popup. Click Authorize. You only do this once.
  9. In the Keys tab, set a key to App action → Discord → Mute / unmute mic or Deafen. It lights green while you're live and red while muted.

It works for the Discord account that owns the app. Declined the popup by mistake? Click Save & connect again.

VoiceMeeter

Uses VoiceMeeter's own remote API on this PC: no account, password or setting in VoiceMeeter needed. Works with Basic, Banana and Potato.

Setup guide

  1. Install VoiceMeeter (Basic, Banana or Potato) and start it.
  2. Turn Enabled on here. The status shows the edition once it's connected.
  3. In the Keys tab, set keys to App action → VoiceMeeter:
    • Mute an input (strip) or output (bus): green while live, red while muted.
    • Route an input to an output (e.g. VStreaming → B1): blue while on.
    • Macro Button toggle or press: amber while the button is on.
  4. Set the knob or the slider to VoiceMeeter → Input / output gain. The slider covers VoiceMeeter's full fader range (−60 to +12 dB).

Notes

  • Names come from VoiceMeeter: give strips a label there (click the name above a strip) to see it here.
  • Macro Buttons need the VoiceMeeter Macro Buttons app running. The numbers are the button IDs shown in it.
  • Changes made in VoiceMeeter itself show on the numpad's lights too.

Numpad settings

Polling rate: how often key presses are sent over USB (Bluetooth has its own timing). Key scan interval (debounce, stock 8 ms): how often the keys are read. Lower is snappier, but a worn switch may double-type. Lighting off when idle: the LEDs (including OBS status lights) switch off until the next key press.

Low battery warning

The side bars pulse the battery gauge for 5 seconds when the numpad connects over Bluetooth and every 5 minutes after that, while the battery stays low. On USB it charges, so it doesn't warn. A key set to PC → Show battery on the side bars shows the level any time.

Profile

Each profile has its own lighting and three layers (each with its own keys, knob and slider), all stored on the numpad. Switch with the buttons at the top, Fn+9 / Fn+7 (profiles) or Fn+3 / Fn+1 (layers).
